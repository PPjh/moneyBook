## 1.5.3 · 2026-10-18

- 修复每次重开都在顶部提示重新授权：区分待确认访问、明确拒绝和已授权状态。
- 已记住文件夹且备份未到期时安静保留设置，不因待确认状态显示警告。
- 备份到期无法写入、权限被拒绝或真实写入失败时仍会提醒；成功备份后清除提醒。

## 1.5.2 · 2026-10-18

- 新增本机固定备份文件夹：首次在系统选择器中授权，后续手动和自动备份保存到同一位置。
- 使用 IndexedDB 记住目录句柄，支持更换位置、重新授权和停用；账本导出不包含目录句柄。
- 自动备份仅在应用打开或解锁且周期到期时执行，不会后台弹出授权请求；需要设置或重新授权时显示提示。
- 文件流关闭成功后才记录备份时间；失败时保留原成功时间，并尝试清理本次未完成的文件。
- 文件名包含日期、秒和毫秒，同名时另取名称，保留历史备份；停用固定位置不会删除已有文件。
- 保留临时下载功能，不支持目录访问的浏览器仍可普通下载。

## 1.5.0 · 2026-10-18

### 新增

- 账目关键词搜索、收支类型与分类组合筛选、跨月查找、筛选结果收支合计。
- 点击月份直接跳转，每月独立预算、预算进度、剩余额度、日均可用与超支提醒。
- 保存并继续记账，保留日期和分类；删除后 8 秒内撤销。
- 浅色、深色、跟随系统三种主题；电脑侧栏与手机底部导航。
- 损坏账本的原始文件导出、存储受限提示、多窗口账本冲突检测。

### 改进

- 重新设计月度汇总、预算卡、筛选栏、记录列表和记账面板；长列表分批加载。
- 写入成功后才更新内存和提示成功；写入失败保留输入，可释放空间后重试。
- 导入严格验证真实日期、金额范围和安全整数；旧备份无 ID 记录生成稳定 ID。
- 覆盖恢复前确认，导入和清空前必须成功创建快照；异常账本恢复前保留原文。
- JSON 备份和本机快照包含预算，覆盖恢复时恢复预算，合并导入保持当前预算。
- CSV 文本字段防止公式注入，导出仍不包含 PIN。
- Service Worker 按路径隔离缓存，预缓存完整后激活，导航遇到服务器错误时使用离线缓存。
- 改进对话框焦点、屏幕阅读器标签、键盘操作与减少动态效果设置。
- 导出提示改为请求下载并要求确认文件，避免将被浏览器拦截的下载误报为已备份。

### 修复

- 手机设置 PIN 缺少确认按钮，新增确认与取消设置。
- 收入增长错误显示为警示色，历史月份的趋势末列错误显示「本月」。
- 金额舍入为零、导入非法日期和原型同名分类导致的异常。
- 初始化后更新检测状态被重置的问题。

### 兼容与发布

- 保留 `jz.records.v1`、`jz.config.v1` 和 `jz.backups.v1` 存储键，兼容现有账目、密码和快照。
- 保持零运行时依赖、离线优先、无账号、无后端。
- 运行 `node build.mjs` 生成 `dist/`，运行 `node check.mjs` 完成回归检查。
- GitHub Pages 从仓库根目录部署，其他静态托管可使用 `dist/`。
