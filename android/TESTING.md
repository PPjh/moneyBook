## 手机验收清单

先用演示账本，不覆盖唯一的真实备份。

- [ ] 安装、首次打开、三个导航页面及记账面板、返回键、小屏／大字体、深浅主题、安全区与软键盘无遮挡。
- [ ] 安卓 8／9 的旧系统栏、刘海屏、横屏和新系统手势导航，确认安全区只处理一次且键盘不遮挡保存按钮。
- [ ] 新增支出与收入、备注分类、历史日期、算式按钮、连续记账、修改、删除及 8 秒撤销。
- [ ] 月预算、筛选／跨月搜索、分类图、六个月趋势、已有／无账目状态。
- [ ] 旋转屏幕与系统回收后恢复；编辑草稿不错误覆盖已有记录。
- [ ] 设置／修改／关闭 PIN、错误 PIN、5 次错误等待、后台延时锁定、重开仍需 PIN。
- [ ] 固定文件夹选择、取消选择、切换目录、立即备份，确认生成的 JSON 可重新导入。
- [ ] 完全关闭后重开、手机重启后再次备份，确认授权保留；尽量在实际要长期使用的文件管理器中测试。
- [ ] 撤销权限、目录删除／不可用、空间不足等情况下提示失败，成功时间不被错误更新，旧备份不受损。
- [ ] 自动备份到期后打开／解锁执行；未到期不开文件选择器；关闭应用期间不承诺后台运行。
- [ ] Web JSON 导入预览、合并不重复、覆盖同步预算、CSV 正确、导出文件不含 PIN 或目录权限。
- [ ] 手动／每日快照、保留 10 份、恢复前快照、清空前快照、取消危险操作。
- [ ] 使用相同签名升级，账目和目录授权保留；不同签名冲突时不直接卸载。

卸载／清除应用数据会删除数据库和本机快照。遇到安装冲突先导出外部备份，正式发布前另行管理稳定签名。
