先用演示账本，不覆盖唯一的真实备份。

- [ ] 安装、首次打开、三个导航页面及记账面板、返回键、小屏／大字体、深浅主题、安全区与软键盘无遮挡。
- [ ] 安卓 8／9 的旧系统栏、刘海屏、横屏和新系统手势导航，确认安全区只处理一次且键盘不遮挡保存按钮。
- [ ] 新增支出与收入、备注分类、历史日期、算式按钮、连续记账、修改、删除及 8 秒撤销。
- [ ] 新增维修支出、编辑、分类筛选、统计和备份恢复；覆盖安装后核对原账目不变。
- [ ] 月预算、筛选／跨月搜索、分类图、六个月趋势、已有／无账目状态。
- [ ] 旋转屏幕与系统回收后恢复；编辑草稿不错误覆盖已有记录。
- [ ] 开启／关闭指纹、取消、错误指纹、系统临时锁定、手机锁屏密码备用、无硬件／未录入指纹、后台延时锁定、冷启动验证。
- [ ] “我的”与原生解锁页没有指纹设置入口；没有可用指纹时只提示，不跳转或要求录入，不误开启开关。
