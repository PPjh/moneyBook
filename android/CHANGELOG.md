# 安卓版更新日志

## 1.2.1 · 指纹界面简化 · 2026-10-20

- 移除“我的”和启动解锁页中的系统指纹设置入口、原生跳转方法及页面接口。
- 没有可用指纹时只提示“未检测到可用指纹”，不引导或跳转系统设置，开关保持关闭。
- 已有指纹保护、旧 PIN 安全迁移及手机锁屏密码备用不变，不清空或迁移账目。
- 版本 code 7，共享 Web 资源为 1.5.8；沿用原包名、数据库和本地测试签名。

## 1.1.1 · 紧凑布局测试版 · 2026-10-19

- 顶部安全区统一由原生容器处理并消费，网页不再重复增加状态栏／刘海／底部安全区；旧安卓版本同步使用边到边布局。
- 手机顶栏内容留白从上 14／下 12 px 收紧为各 6 px，不隐藏系统状态栏或让内容压到刘海下。
- 缩小手机月度收支、预算和统计指标卡的内边距及金额字号，保留全部数据与预算操作，桌面布局不变。
- 390 × 844 浏览器测试中，收支＋预算区域由 367 px 降至约 268 px，收支明细标题上移约 117 px。
- 新增 320／360／390／412／600 宽度和模拟安全区检查，Web 与安卓共享页面截图继续一致。
- 版本 code 3，沿用原签名和数据库；Web 共享界面更新至 1.5.4。实际手机的系统栏、刘海及软键盘仍需验收。

## 1.1.0 · 共享界面测试版 · 2026-10-19

- 直接打包 Web 的同一份 HTML、CSS 与图标，统一明细、统计、我的、记账面板、图表与 PIN 键盘。
- 通过本机桥接继续使用原 SQLite 数据库、原生 PBKDF2 PIN、固定目录持久授权和私有快照，不搬到浏览器存储。
- 保持包名与本地签名、版本递增为 code 2；数据库仅新增配置表，旧 PIN 首次可手动确认位数。
- 增加原生存储严格校验、恢复与预算事务、备份时间并发保护、界面适配失败时停止写入保护。
- 禁止网络、外部页面、iframe 和文件 URL，只加载 APK 内的受限资源。
- 26 项 JVM 测试、418 项 Web 自检通过；真实浏览器内四种界面截图逐像素相同，原生适配桩测试通过。
- 系统弹窗保留安卓样式，实际 WebView／真机升级仍需验收。

## 1.0.0 · 本地测试版

- 建立原生 Java / Android Views 工程，最低 Android 8.0（API 26），编译与目标 API 35。
- 橙色主题、沿用现有图标、浅色／深色／跟随系统、四个主要页面与系统安全区适配。
- SQLite 账目与预算，记账、编辑、删除、8 秒撤销、连续记账、金额四则算式。
- 月份切换、关键词／类型／分类筛选、跨月搜索、按天分组和每批 100 条展示。
- 月度预算、本月统计、分类环形图与近六个月收支趋势。
- 加盐 PBKDF2 PIN、后台延时锁定；不将 PIN 放入账目备份。
- 安卓系统目录选择与持久 URI 授权；手动及打开／解锁时到期备份、周期设置、失败提示。
- Web JSON 互导、恢复预览、合并／覆盖、事务写入、CSV 导出、原子文件快照与恢复。
- 添加核心 JUnit 测试和 GitHub Actions 检查、打包、测试 APK 产物上传。
- 提供无 Gradle 下载的官方 SDK 本地打包脚本；完整源码编译、APK 签名与 ZIP 对齐校验通过，19 项核心测试通过。

编译和设备测试状态见 [README](README.md)。源码功能完成不等于已通过真机验收。
